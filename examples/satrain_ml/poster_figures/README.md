Final figures used on the project poster. Each has a .pdf (print) and .png (slides/web).

- fig1_observing_systems — GMI + ABI example scene.
- fig2_input_stack — schematic of the model input stack.
- fig3_unet — baseline U-Net architecture diagram.
- fig4_transformer — transformer architecture diagram.
- fig6_skill_barchart — skill comparison across the three models.

Figures 3 and 4 are drawn with ../PlotNeuralNet/ (vendored third-party tool).

Generated by ../make_poster_figures.py, which also produces two figures not present here:
fig5 (retrieval scene comparison) and fig7 (predicted-vs-observed scatter) — both need
model evaluation output from satrain_torch/eval_out/, which was not migrated (see the
top-level README's "Known gaps" section). ../fig6_barchart.py is a standalone alternate
generator for fig6.
